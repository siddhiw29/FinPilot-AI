# FinPilot AI

FinPilot AI is a Python-based personal finance analytics project that helps users analyze bank transactions, categorize expenses using Large Language Models (LLMs), and visualize spending patterns through interactive dashboards.

## Features

- Automatic expense categorization using Llama 2
- Personal finance dashboard
- Transaction analysis
- Spending insights
- CSV transaction processing
- Data visualization

## Tech Stack

- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Ollama
- Llama 2

## Project Structure

- categorize_expenses.ipynb
- categorize_expenses_with_validation.ipynb
- dashboard.ipynb
- transactions_2022_2023.csv
